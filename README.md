# 📱 Meta Ad Performance Analysis Dashboard | Power BI

## 📌 Project Title

**Meta Ad Performance Analysis Dashboard**

---

## 📖 Project Description

This project presents an interactive **Meta Ad Performance Analysis Dashboard** developed using Power BI to analyze paid advertising campaigns running across **Facebook and Instagram**.

The dashboard transforms advertising event data into meaningful business insights by analyzing campaign reach, clicks, engagement, conversions, budget utilization, audience behavior, platform performance, and ad-type performance.

The project focuses on helping marketing stakeholders understand which platforms, audience segments, ad formats, and time periods are performing best and where advertising budgets can be optimized for better campaign effectiveness.

## 📂 Data Source

The analysis is based on Meta advertising campaign data covering paid advertisements on:

- Facebook
- Instagram

The project uses advertising event data along with campaign, ad, user, platform, audience, and time-related information.

**Scope:** Paid ads on Facebook and Instagram only.

**Out of Scope:** Messenger, Audience Network, and organic engagement. :chatgpt-content-reference{index="1"}

# 🚀 Dashboard Highlights

## 📌 Business Problem

Marketing teams need to continuously evaluate advertising campaigns across different platforms and audience segments. Without a centralized analytical dashboard, it can be difficult to determine which platform performs better, which audience responds most effectively, and whether the advertising budget is being utilized efficiently.

This dashboard provides a centralized view of campaign performance to help marketing teams monitor results and identify opportunities for optimization.

---

## 🎯 Goal of Dashboard

The main goal of this dashboard is to:

- Compare Facebook vs Instagram performance.
- Monitor campaign reach and engagement.
- Analyze clicks, shares, comments, and purchases.
- Evaluate CTR and conversion performance.
- Identify high-performing audience segments.
- Analyze ad performance by type.
- Understand geographic campaign performance.
- Identify weekly, monthly, and hourly performance patterns.
- Support better advertising budget allocation.

The BRD specifically identifies platform effectiveness, ROI/budget optimization, and audience engagement as key business objectives. :chatgpt-content-reference{index="2"}

# 📊 Key Performance Indicators (KPIs)

### 👁️ Impressions
Measures the number of times advertisements were displayed.

### 🖱️ Clicks
Measures the number of times users clicked on advertisements.

### 🔄 Engagements
Total interactions calculated from:

**Clicks + Shares + Comments**

### 🛒 Purchases
Measures the number of purchases generated after users interacted with advertisements.

### 📈 CTR – Click Through Rate
Measures the percentage of impressions that resulted in clicks.

### 💬 Engagement Rate
Measures the percentage of impressions that resulted in engagements.

### 🛍️ Conversion Rate
Measures the percentage of clicks that resulted in purchases.

### 🛒 Purchase Rate
Measures the percentage of impressions that resulted in purchases.

### 💰 Total Budget
Measures the total budget allocated across campaigns.

### 💵 Average Budget per Campaign
Measures the average budget allocated to each campaign.

The KPI definitions and formulas follow the provided Business Requirements Document. :chatgpt-content-reference{index="3"}
